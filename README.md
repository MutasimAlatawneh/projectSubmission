# Discovery Web Piscine

Hey there! This is my submission for the Discovery Web Piscine. This folder covers getting comfortable with the Linux terminal, automating basic file tasks with shell scripts, recording Git workflows, and setting up secure SSH authentication for GitHub.

## What's in this folder?

* `ex00/` - Terminal navigation and directory structuring. Contains `tree_structure.txt`, which maps out the custom `dev_workspace` folder tree built purely through command-line operations.
* `ex01/` - File manipulation and text streams. Includes `manage_files.sh` (a custom script handling file creation, text redirection, copying, moving, and cleanup) along with `run_log.txt` capturing its execution.
* `ex02/` - has the repo_url.txt and gitlog.txt.
* `ex03/` - Project documentation and version control workflows. Features this `README.md`, my `git_workflow.txt` log, and `id_ed25519_pub.txt` (the bonus SSH public key used to connect securely to GitHub without typing passwords every time).
